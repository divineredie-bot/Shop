# Anime Shop

Небольшое веб-приложение интернет-магазина с корзиной товаров.

## Возможности

- Отображение карточек товаров
- Добавление товаров в корзину
- Изменение количества одинаковых товаров
- Подсчёт общей стоимости корзины
- Отображение количества добавленных товаров
- Отдельная страница корзины
- Анимация добавления товара в корзину
- Динамическое обновление содержимого корзины

## Технологии

- HTML5
- CSS3
- JavaScript (ES6+)
- DOM API
- CSS Animations

## Особенности реализации

При добавлении товара приложение обновляет состояние корзины и количество товаров. Одинаковые товары не создаются отдельными позициями — вместо этого увеличивается их количество.

Общая стоимость корзины рассчитывается динамически на основе количества товаров и их цены.

Также реализована анимация перемещения карточки товара к кнопке корзины при добавлении.
